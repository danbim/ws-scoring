# Introducing solid-ui: Button Component Migration

## Overview

Introduce [solid-ui](https://www.solid-ui.com/) (an unofficial shadcn/ui port for SolidJS) to the project, starting with the Button component. solid-ui uses Kobalte for headless primitives, CVA for variant composition, and Tailwind CSS variables for theming.

## Setup

### New Dependencies

```
tailwindcss-animate       # Tailwind animation utilities
class-variance-authority  # Variant-based class composition (CVA)
clsx                      # Class string construction
tailwind-merge            # Intelligent Tailwind class merging
@kobalte/core             # Headless UI primitives (used by solid-ui Button)
```

### Configuration Changes

**`tailwind.config.js`** - Extend with:
- CSS variable-based color tokens (`--primary`, `--secondary`, `--destructive`, etc.)
- Dark mode support (`class` strategy + `[data-kb-theme="dark"]`)
- `tailwindcss-animate` plugin
- Animation keyframes (accordion open/close, content show/hide)

**`src/app/index.css`** - Add `@layer base` with CSS variables:
- Light mode (`:root`) mapped from current color scheme:
  - `--primary`: indigo-600 equivalent
  - `--destructive`: red-600 equivalent
  - `--secondary`: gray-200 equivalent
  - Plus: background, foreground, muted, accent, popover, card, border, input, ring
- Dark mode (`.dark`, `[data-kb-theme="dark"]`): inverted palette

**`vite.config.ts`** - Add resolve alias:
```ts
resolve: {
  alias: {
    "@": path.resolve(__dirname, "./src")
  }
}
```

**`src/lib/utils.ts`** - New utility file:
```ts
import type { ClassValue } from "clsx"
import { clsx } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

### New Component File

**`src/components/ui/button.tsx`** - Generated by `solidui-cli`, CVA-based Button wrapping Kobalte's Button primitive.

## Variant Mapping

| Current variant | solid-ui variant | Notes |
|---|---|---|
| `primary` | `default` | Primary CTA, the default |
| `secondary` | `secondary` | Direct match |
| `danger` | `destructive` | Solid background destructive action |
| `success` | `default` | Positive CTAs become standard primary |
| `text` | `ghost` | Transparent background, text on hover |
| `danger-text` | `ghost` + `class="text-destructive hover:text-destructive"` | Text-only destructive |

| `size="lg"` | `size="lg"` |

## Color Theme (CSS Variables)

Map current Tailwind colors to HSL CSS variables to preserve the visual appearance:

- **Primary (indigo-600)**: `--primary: 239 84% 67%`
- **Destructive (red-600)**: `--destructive: 0 72% 51%`
- **Secondary (gray-200)**: `--secondary: 220 13% 91%`
- **Background**: `--background: 0 0% 100%`
- **Foreground**: `--foreground: 224 71% 4%`
